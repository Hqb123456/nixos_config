# AGENTS.md
## 构建命令

```bash
# 构建所有解决方案
make

# 构建单个文件
g++ -std=c++17 -O3 -Wall <file>.cpp -o build/<file>

# 清理构建产物
make clean
```

## 注意事项

- 源文件：`*.cpp`（根目录下）
- 构建产物：`build/` 目录
- 编译器：`g++ -std=c++17 -O3 -Wall`
- 文件排除：文件名以 `#` 开头或以 `~` 结尾的文件会被忽略
- 文件名包含冒号的文件也会被忽略
- 每个 `.cpp` 是独立的算法问题解答
- 必须使用中文回答问题和思考
